# Personal Portfolio Website using React.js and Tailwind CSS

This is my personal portfolio website built with React.js and Tailwind CSS. It showcases my skills, projects, and experience as a web developer. The website is responsive and provides a smooth and modern user experience.

## Live Demo: https://shubhamjhaportfolio.netlify.app/

## Features
▫ Home Section: Introduction with a short bio and my professional background.

▫ Skills Section: A list of technologies and tools I'm proficient in.

▫ Projects Section: Showcases various web development projects I've worked on.

▫ Contact Section: A form for getting in touch with me, with links to my social media and contact information.

▫ Responsive Design: The website is fully responsive across devices (mobile, tablet, and desktop).

▫ Smooth Animations: Custom animations for scrolling and interacting with various elements.

▫ Tailwind CSS: Used for styling to keep the website clean and easy to customize.

## Technologies Used
▫ React.js: A JavaScript library for building user interfaces.

▫ Tailwind CSS: A utility-first CSS framework for rapidly building custom designs.

▫ React Router: For navigation between different sections of the portfolio.

▫ React Icons: Used to add icons for social media links and other interactive elements.
